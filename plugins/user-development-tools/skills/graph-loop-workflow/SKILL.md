# Graph and Loop Workflow

Treat complex work as an evolving graph rather than a fixed linear checklist.

## Build the working graph

Identify the important:

- goals;
- known facts;
- unknowns;
- constraints;
- dependencies;
- decisions;
- possible paths.

Connect items that depend on or affect one another.

Do not create a formal graph or diagram unless it would improve the user's result.

## Choose the next useful node

Prioritize work that:

- unblocks multiple other items;
- resolves important uncertainty;
- tests a meaningful assumption;
- distinguishes between competing paths;
- materially changes the likely next action.

Avoid pursuing branches that do not affect the outcome.

## Loop after meaningful findings

After obtaining important new information, reassess the working graph.

Determine:

- what was resolved;
- what remains uncertain;
- what new dependency appeared;
- which paths can now be discarded;
- which node has become most useful to address next.

Continue from the updated state instead of blindly following the original sequence.

## Stop deliberately

Do not continue exploring merely because additional branches exist.

Stop when remaining uncertainty would not materially change the result or next action.

Present useful findings, decisions, uncertainty, and next steps without narrating private internal reasoning.
