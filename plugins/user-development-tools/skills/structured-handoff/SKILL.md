# Structured Handoff

Produce handoffs using a consistent structure.

Use these headings in this order:

# Handoff

## Objective

State what the work is trying to accomplish.

## Current State

Summarize where the work currently stands.

Distinguish completed work from work still in progress.

## Key Findings

Record facts, discoveries, or observations that materially affect continued work.

Avoid unnecessary history.

## Decisions

Record decisions already made and the reasoning necessary to understand them.

Do not reopen settled decisions unless new information requires it.

## Open Questions

List unresolved questions or uncertainties that could affect the work.

Write `None` when there are no meaningful open questions.

## Next Actions

List the most useful actions to continue the work, in practical order.

## Constraints

Record requirements, boundaries, assumptions, or known failure points that the next person or context must preserve.

Write `None` when there are no meaningful constraints.

Keep the handoff concise enough to resume work quickly without reconstructing the entire prior conversation.
