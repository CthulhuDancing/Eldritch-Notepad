# Documentation README
Use this document to make sense of the /docs/ directory.

## Inventory of Directories
- `testing/` is the directory for housing Documentation about repo tests.
- `testing/prompts/` is the directory for housing test prompts for skill updates.

## Inventory of root docs
- `Decisions.md` is the durable source of truth for decision making logic and past reasoning.
- `README.md` is this directory's authoritative index guide and explanation of contents.
- `Roadmap.md` is the project radmap and outstanding issues tracker.
- `VersionHistory.md` is the record source for historical versions and changes.

## Inventory of Test Prompts
- `testing/prompts/plugin-health-report.prompt.md` is the default testing prompt to query plugin & skill availability.
