# Version History
Use this document to capture version history snapshots. Compared with Decisions.md to get a good understanding of intent + implementation.

## 0.1.0
Initialize Repo for generic Agentic Marketplace. Initialize with only one plugin `project-workflow-tools` containing 2 lean skills to help users get more out of their agent.
- Created `adaptive-workflow` skill. This skill helps your agent tackle prompts in a more graph-loop manner rather than linearly or all at once.
- Created `structured-handoff` skill. This skill helps your agent to produce consistent and easy to understand handoffs for when work must move to a new chat / user / agent / etc.
- Created `Decisions.md`, `Roadmap.md`, `VersionHistory.md` and `testing/prompts/plugin-health-report.prompt.md`. These documents form the core of the project's documentation and outline core decision making, historical changes & future planned work for iterative development.
- Expand Testing Documentation with `testing/Inventory.md` to document test purpose + pass /fail conditions.

Also included placeholder readme documents & necessary marketplace & plugin Manifests
